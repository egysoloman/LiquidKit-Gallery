# LiquidKit Gallery

Android Jetpack Compose component gallery showcasing **LiquidKit** UI components and AGSL Liquid Glass effects.

## Download

- **APK**: [LiquidKit-Gallery.apk](./LiquidKit-Gallery.apk)

## Highlights

- **14 Categories & 46 Component Demos**: Liquid Glass surfaces & containers, interactive buttons & controls, text & rich editing, pickers & sliders, indicators & gauges, layouts & lists, navigation & sheets, graphics & animations, charts, gestures & haptics, and WebView/Canvas demos.
- **Built-in Kotlin Code Snippets**: Expand and copy runnable LiquidKit Compose examples directly inside each component demo.
- **Light / Dark / System Appearance**: Switch appearance modes live from the gallery header.
